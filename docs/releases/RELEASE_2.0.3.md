# Life Assistant 2.0.3

## Changed

- **Ticked checklist items move out of the way, like todos.** The daily checklist on Today shows
  only what is left for the day. A ticked item moves into a folded **Checked off** group under
  the list; open it to see what is done, and tap an item there to untick it and bring it back.
  Once everything is ticked, a line says so until the next morning.
- **Today no longer has a field for adding todos.** Add todos in Todo; the ones due today still
  show on Today and are ticked off there.

## Compatibility

- Signed with the same key as 2.0.2: install it over 2.0.2 without uninstalling.
- The backup and sync format is the same as in 2.0.2.
